Minecraft Translator - бесплатная программа для автоматического перевода сборок Minecraft с английского на русский.

Выберите папку сборки, и программа сама найдёт моды, переведёт тексты через Google Translate и применит перевод: создаст ресурспак, включит его в настройках игры и поставит русский язык. Переводятся названия предметов и блоков, подсказки, квесты, книги Patchouli, конфиги и скрипты KubeJS. Технические данные (ID, ссылки, плейсхолдеры и цветовые коды) и названия модов остаются нетронутыми.

Перед изменениями программа делает резервную копию. Если что-то пойдёт не так, файлы возвращаются обратно. Готовые переводы сохраняются в кэше, поэтому повторный запуск идёт быстрее. Программа распространяется бесплатно по лицензии MTFUL
